# Brutal navigation

## Use it for

A creative portfolio, event, music project, or youth brand that benefits from direct typography and visible structure.

## Files

Copy `index.html` and `style.css`, plus `script.js` for the mobile menu.

## Edit first

Replace the content beside the `EDIT` comment. Change the palette, border weight, and paper color under `/* EDIT: theme */`. The root selector is `.brutal-nav`.

## Behavior

The menu exposes its open state with `aria-expanded` and keeps its links usable in the source HTML.

## Accessibility

Keep the semantic landmark, logical headings, visible labels, and focus outline. Strong color never replaces a written state or instruction.
