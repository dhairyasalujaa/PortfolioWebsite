# Studio navigation

## Use it for

A minimal studio, portfolio, architecture, or professional-services website that needs a precise navigation.

## Files

Copy `index.html` and `style.css`, and keep `script.js` beside them for the mobile menu.

## Edit first

Replace content beside the `EDIT` comment in `index.html`. Change the six theme values under `/* EDIT: theme */` in `style.css`. The component root is `.studio-nav`.

## Behavior

The menu button controls the mobile navigation at 720px and below. Content remains present in the HTML when JavaScript is unavailable.

## Accessibility

Keep the existing semantic element, heading order, visible focus styles, and text labels. When replacing artwork, add useful alternative text for meaningful images and empty alternative text for decoration.
