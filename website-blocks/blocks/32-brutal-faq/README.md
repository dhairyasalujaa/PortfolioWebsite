# Brutal FAQ

## Use it for

A standalone specialty section for expressive portfolios, agencies, product sites, and publications. Copy the whole folder into your project.

## Files

`index.html` and `style.css`. Open `index.html` directly to preview it; there are no packages or external runtime dependencies.

## Edit first

Search for `EDIT:` in the HTML and CSS. Replace all sample content, links, and the theme variables at the top of `style.css`.

## Behavior

Native `details` elements work without JavaScript and allow more than one answer to remain open.

## Accessibility

Semantic HTML, visible focus states, readable contrast, and a mobile layout are included. Keep disclosure semantics and image descriptions meaningful.
