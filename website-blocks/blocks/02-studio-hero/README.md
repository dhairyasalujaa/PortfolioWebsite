# Studio hero

## Use it for

A minimal studio, portfolio, architecture, or professional-services website that needs a precise hero.

## Files

Copy `index.html` and `style.css`.

## Edit first

Replace content beside the `EDIT` comment in `index.html`. Change the six theme values under `/* EDIT: theme */` in `style.css`. The component root is `.studio-hero`.

## Behavior

This block needs no JavaScript. Links and form actions are examples and should be replaced before publishing.

## Accessibility

Keep the existing semantic element, heading order, visible focus styles, and text labels. When replacing artwork, add useful alternative text for meaningful images and empty alternative text for decoration.
