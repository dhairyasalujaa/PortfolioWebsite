# Product FAQ

## Use it for

A standalone section for product sites, SaaS landing pages, and friendly digital services. Copy the whole folder into your project.

## Files

`index.html`, `style.css`, and `script.js`. Open `index.html` directly to preview it; there are no packages or external runtime dependencies.

## Edit first

Search for `EDIT:` in the HTML and CSS. Replace the sample copy, links, form destination, and the theme variables at the top of `style.css`.

## Behavior

The accordion keeps at most one answer open. Without JavaScript, all answers remain readable.

## Accessibility

Visible focus states, semantic landmarks, readable contrast, and a mobile layout are included. Keep labels and ARIA relationships intact when changing content.
