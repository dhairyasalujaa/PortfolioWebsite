# Editorial Navigation

## Use it for

A standalone section for editorial sites, premium portfolios, publications, and culture-led brands. Copy the whole folder into your project.

## Files

`index.html`, `style.css`, and `script.js`. Open `index.html` directly to preview it; there are no packages or external runtime dependencies.

## Edit first

Search for `EDIT:` in the HTML and CSS. Replace sample copy and links, then tune the theme variables at the top of `style.css`.

## Behavior

The section menu becomes a drawer below 720px. `setEditorialMenu` is exported for testing.

## Accessibility

Semantic regions, visible focus states, readable contrast, and a mobile layout are included. Preserve form labels and ARIA relationships when editing.
