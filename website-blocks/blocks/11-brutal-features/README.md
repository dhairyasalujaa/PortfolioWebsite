# Brutal features

## Use it for

A creative portfolio, event, music project, or youth brand that benefits from direct typography and visible structure.

## Files

Copy `index.html` and `style.css`.

## Edit first

Replace the content beside the `EDIT` comment. Change the palette, border weight, and paper color under `/* EDIT: theme */`. The root selector is `.brutal-features`.

## Behavior

No JavaScript is required. Replace example links before publishing.

## Accessibility

Keep the semantic landmark, logical headings, visible labels, and focus outline. Strong color never replaces a written state or instruction.
