# Portfolio redesign

This folder contains a self-contained static redesign of Dhairya Saluja's
portfolio. It does not depend on the website files in the parent folder.

Open `index.html` directly, or start the included local preview server:

```powershell
node tests/server.js
```

Then visit `http://127.0.0.1:4173/`.

Run the structural checks from the repository root:

```powershell
node portfolio-redesign/tests/site.test.js
```
